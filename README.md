# LaundryMart

A responsive laundry services website built using HTML and CSS. The website provides a simple interface for exploring laundry services and booking a service.

## Features

* Responsive navigation bar
* Hero section with service information and image
* Services section
* About and contact sections
* Responsive layout using CSS media queries
* Flexbox for layout management

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Media Queries

## Project Structure

```text
LaundryMart/
│
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or any web browser.

## Purpose

Created as a CSS practice project to understand Flexbox, responsive web design, and media queries.
